# MIDI Tools

> [Русский](README_ru.md) | [中文](README_zh.md)

Инструмент для редактирования MIDI в виде текста и экспорта аудио, работающий полностью в браузере без зависимостей. Сочиняйте музыку с помощью частотных соотношений чистого строя (Just Intonation), с воспроизведением в реальном времени, выбором формы волны и экспортом в WAV/MIDI.

---

## Быстрый старт

Откройте `index.html` в любом современном браузере — установка не требуется.

## Возможности

### MIDI-редактор

Записывайте ноты в виде простого текста, воспроизводимого последовательно сверху вниз. Одна нота на строку, четыре поля, разделённых запятыми:

| Поле       | Формат      | Описание | По умолчанию |
|------------|-------------|----------|--------------|
| Длительность | `числ/знам` | `1/1` = четвертная, `1/2` = восьмая, `1/8` = тридцать вторая | `1/1` |
| Высота     | `числ/знам` | Частотное соотношение чистого строя. `1/1` = тоника, `4/3` = чистая кварта, `3/2` = чистая квинта | `1/1` |
| Размер     | `01` ~ `10` | Двузначное число, управляет громкостью (velocity) | `10` |
| ID         | `00` ~ `99` | Двузначный идентификатор, не влияет на воспроизведение | пусто |

Пример:

```
1/1,1/1,10,01
1/1,9/8,10,02
1/1,5/4,10,03
1/1,4/3,10,04
1/1,3/2,10,05
1/1,5/3,10,06
1/1,15/8,10,07
1/1,2/1,10,08
```

Строки, начинающиеся с `//` или `#`, считаются комментариями.

#### Возможности редактора

- **Мгновенный парсинг** — разбор при вводе; строки с ошибками подсвечиваются красным с номерами строк
- **Воспроизведение / Пауза / Стоп** — возобновление с места паузы
- **Регулировка BPM** — 20–400 BPM, через ползунок и числовой ввод
- **Множитель скорости** — 0.25x–4x, с быстрыми пресетами: 0.5x / 1x / 1.5x / 2x
- **Базовая частота** — по умолчанию 261.63 Гц (до первой октавы), свободно настраивается
- **Громкость** — 0–100%
- **Форма волны** — треугольная / синусоидальная / прямоугольная / пилообразная
- **Огибающая ADSR** — каждая нота формируется с атакой, спадом, поддержкой и затуханием
- **Обертонный слой** — к каждой ноте добавляется синусоидальный обертон на удвоенной частоте
- **Подсветка воспроизведения** — текущая строка и номер строки подсвечиваются при воспроизведении
- **Панель информации о ноте** — отображение длительности, высоты, частоты, громкости и ID в реальном времени
- **Встроенные шаблоны** — гамма чистого строя, мелодия «Twinkle Twinkle», аккордовые последовательности
- **Импорт / Экспорт** — импорт `.txt` файлов партитур, экспорт в `.txt`
- **Автосохранение** — содержимое редактора автоматически сохраняется в localStorage

#### Горячие клавиши

| Клавиша    | Действие              |
|------------|-----------------------|
| `Space`    | Воспроизведение / Пауза |
| `Escape`   | Стоп                  |
| `Ctrl+S`   | Экспорт партитуры     |
| `Tab`      | Вставить отступ       |

### Экспорт аудио

Переключитесь на вкладку «Экспорт аудио», чтобы преобразовать ноты редактора в аудиофайлы.

#### Экспорт в WAV

- Использует OfflineAudioContext для офлайн-рендеринга, точно воспроизводя звук редактора
- Поддерживает частоты дискретизации 44100 / 48000 / 96000 Гц
- Поддерживает глубину 16-bit / 24-bit
- Сохраняет выбор формы волны, огибающую ADSR и обертонное смешивание

#### Экспорт в MIDI

- Преобразует частотные соотношения чистого строя в ближайшие стандартные номера MIDI-нот
- По умолчанию используется акустический рояль (Program 0)
- Два режима длительности нот:
  - **Фактическая длительность** — точное соответствие длительностям, заданным в партитуре
  - **Фиксированная восьмая** — все ноты приводятся к длительности восьмой
- Стандартный MIDI Format 0, PPQN = 480

#### Предпросмотр экспорта

- Отображение количества нот, общей длительности (в долях), эффективного BPM, примерной длительности (в секундах)
- Предпросмотр списка нот, автоматически обновляется при переключении на вкладку

## Архитектура

### Совместимость с браузерами

- Требуется Web Audio API (поддерживается всеми современными браузерами)
- Рекомендуется: последние версии Chrome / Edge / Firefox

### Основные модули

| Модуль                 | Файл                | Назначение |
|------------------------|---------------------|------------|
| Навигация по вкладкам  | `app.js` (L1–31)    | Переключение вкладок и координация состояний |
| Движок MIDI-редактора  | `app.js` (L33–590)  | Парсинг, воспроизведение, пауза, обновление UI |
| Инструмент экспорта    | `app.js` (L592–898) | Кодирование WAV, генерация MIDI, офлайн-рендеринг |
| Таблица стилей         | `style.css`         | Тёмная тема, адаптивная вёрстка |

### Конвейер аудиодвижка

```
Editor Input
    │
    ▼
parseEditor() ── разбор текста в parsedNotes[]
    │
    ▼
play() ── планирование осцилляторов через AudioContext
    │
    ├── Oscillator (основной тон) ── Gain (ADSR) ──┐
    │                                                ├── destination
    ├── Oscillator (2× обертон)  ── Gain ──────────┘
    │
    ▼
scheduleUIUpdates() ── подсветка воспроизведения через requestAnimationFrame
```

## Философия проекта

- **Чистый строй прежде всего** — высота выражается частотными соотношениями, не привязанными к двенадцатитоновой равномерной темперации; поддерживаются любые системы настройки
- **Текст как партитура** — читаемо и редактируемо, удобно для контроля версий, обмена и пакетного редактирования
- **Ноль зависимостей** — только HTML/CSS/JS, без фреймворков и инструментов сборки
- **Полностью офлайн** — все ресурсы локальны, подключение к сети не требуется
